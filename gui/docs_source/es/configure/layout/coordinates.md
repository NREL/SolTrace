---
title: "Sistemas de Coordenadas"
---

Las coordenadas locales se miden respecto al padre del elemento. Las coordenadas globales se miden en el sistema de coordenadas de la escena despues de aplicar las transformaciones del padre.

Use coordenadas locales para posicionar un elemento dentro de una etapa o elemento padre. Use coordenadas globales para hacer coincidir una ubicacion absoluta de la escena.
