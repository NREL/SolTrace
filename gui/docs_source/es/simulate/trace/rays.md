---
title: "Conteos de Rayos"
---

El numero de rayos controla cuantos rayos intenta lanzar el trazado. Mas rayos reducen el ruido estadistico, pero tardan mas en ejecutarse.

El numero maximo de rayos limita cuantos registros de rayos trazados se conservan para analisis. Los nucleos de CPU controlan cuantos hilos pueden usar los trazadores de CPU. La semilla permite repetir trazados de forma reproducible.
